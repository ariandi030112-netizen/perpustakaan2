Halaman 3 🌐 HTML — Bab 1

🌐 HTML — Pengenalan

HTML (HyperText Markup Language) adalah bahasa markup yang menjadi kerangka dasar setiap halaman web. Bukan bahasa pemrograman, tapi tanpanya web gak akan ada.

HTML pertama kali dibuat oleh Tim Berners-Lee pada tahun 1991. Saat ini versi terbarunya adalah HTML5 yang mendukung multimedia, semantic, dan API modern.

💡 Fakta: HTML bukan bahasa pemrograman karena gak punya logika (if/else, loop, dll). Tapi HTML adalah fondasi semua website.

Kenapa Harus Belajar HTML?

  • 🌍 Dasar dari semua website
  • 📱 Didukung semua browser
  • 🔗 Mudah dipelajari dan langsung terlihat hasilnya
  • 💼 Skill wajib untuk web developer
Halaman 4 🌐 HTML — Bab 1

🏗️ HTML — Struktur Dasar

Setiap dokumen HTML memiliki struktur standar yang harus diikuti:

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Judul Halaman</title> </head> <body> <!-- Semua konten di sini --> </body> </html>

Penjelasan Elemen:

  • <!DOCTYPE html> — deklarasi HTML5, wajib di awal.
  • <html> — elemen root, semua konten di dalamnya.
  • <head> — meta data, title, CSS, script (tidak terlihat).
  • <body> — semua konten yang terlihat di browser.
⚠️ Penting: Selalu gunakan <!DOCTYPE html> agar browser render dengan mode standar.

Komentar di HTML

Komentar digunakan untuk memberi catatan pada kode, tidak akan terlihat di browser.

Atribut HTML

Atribut memberi informasi tambahan pada elemen HTML.

<tag atribut="nilai">...</tag> <!-- Contoh --> <a href="https://example.com" target="_blank">Link</a> <img src="gambar.jpg" alt="Deskripsi" width="200" height="100"> <p id="paragraf1" class="teks-biru">...</p>

Halaman 12 🎨 CSS — Bab 1

🎨 CSS — Pengenalan

CSS (Cascading Style Sheets) digunakan untuk mendekorasi dan mengatur tata letak halaman web.

CSS pertama kali diperkenalkan pada tahun 1996 dan sekarang sudah mencapai versi CSS3 dengan fitur yang sangat lengkap.

Cara Menulis CSS

  • Inline — langsung di elemen: style="color: red;"
  • Internal — di dalam tag <style> di <head>
  • External — file terpisah style.css lalu di-link
<!-- Inline --> <p style="color: blue; font-size: 20px;">Teks biru</p> <!-- Internal --> <style> p { color: green; } </style> <!-- External --> <link rel="stylesheet" href="style.css">
Halaman 13 🎨 CSS — Bab 1

🎯 CSS — Selector

Selector digunakan untuk memilih elemen yang akan diberi style.

/* 1. Selector Elemen */ p { color: blue; font-size: 16px; } /* 2. Selector Class (.) */ .judul { font-weight: bold; text-align: center; } /* 3. Selector ID (#) */ #header { background: #1a1a2e; padding: 20px; } /* 4. Selector Gabungan */ h1, h2, h3 { font-family: 'Segoe UI', sans-serif; } /* 5. Selector Turunan (descendant) */ div p { margin-left: 20px; } /* 6. Selector Anak (child) */ ul > li { list-style: none; } /* 7. Selector Atribut */ input[type="text"] { border: 2px solid #ff6b35; } /* 8. Pseudo-class */ a:hover { color: #ff6b35; } input:focus { outline: 3px solid #ff6b35; } p:first-child { font-weight: bold; }
💡 Tips: Gunakan class untuk style yang reusable. ID hanya untuk elemen unik.
Halaman 14 🎨 CSS — Bab 1

⚖️ CSS — Spesifisitas & Cascade

Spesifisitas menentukan style mana yang akan diterapkan jika terjadi konflik.

Urutan Prioritas (dari tertinggi ke terendah):

  1. !important — memaksa style (hindari!).
  2. Inline style — langsung di elemen.
  3. ID — #header
  4. Class, Pseudo-class, Atribut — .judul, :hover, [type]
  5. Elemen — p, div
/* Contoh spesifisitas */ #header { color: red; } /* ID = 100 */ .header { color: blue; } /* Class = 10 */ header { color: green; } /* Elemen = 1 */ /* Yang menang: #header (red) */ /* !important mengalahkan semuanya */ p { color: purple !important; }

Cascade (Aliran CSS)

  • CSS dibaca dari atas ke bawah.
  • Style yang terakhir akan menimpa yang sebelumnya (jika spesifisitas sama).
  • Gunakan cascade untuk membuat kode lebih terstruktur.
⚠️ Hindari !important — karena bisa membuat kode sulit di-maintain. Gunakan spesifisitas yang tepat.

Halaman 17 🎨 CSS — Bab 2

📐 CSS — Display & Position

Display

  • block — mengambil seluruh lebar, bisa diatur width/height.
  • inline — hanya selebar konten, gak bisa diatur width/height.
  • inline-block — inline tapi bisa diatur width/height.
  • none — elemen hilang (tidak terlihat).
  • flex — display flexbox.
  • grid — display grid.
.block { display: block; } .inline { display: inline; } .inline-block { display: inline-block; } .hidden { display: none; } .flex { display: flex; } .grid { display: grid; }

Position

  • static — default, mengikuti aliran normal.
  • relative — posisi relatif terhadap posisi normal.
  • absolute — posisi relatif terhadap parent terdekat yang bukan static.
  • fixed — posisi tetap di viewport (tidak ikut scroll).
  • sticky — gabungan relative + fixed.
.relative { position: relative; top: 10px; left: 20px; } .absolute { position: absolute; top: 0; right: 0; } .fixed { position: fixed; bottom: 0; left: 0; width: 100%; } .sticky { position: sticky; top: 0; }
Halaman 18 🎨 CSS — Bab 3

📐 CSS — Flexbox

Flexbox adalah layout satu dimensi (baris atau kolom) yang sangat fleksibel.

Properti Flex Container

.container { display: flex; flex-direction: row; /* row | row-reverse | column | column-reverse */ justify-content: center; /* horizontal: flex-start | center | flex-end | space-between | space-around */ align-items: center; /* vertical: flex-start | center | flex-end | stretch */ gap: 20px; flex-wrap: wrap; /* nowrap | wrap | wrap-reverse */ }

Properti Flex Item

.item { flex: 1; /* shorthand untuk flex-grow, flex-shrink, flex-basis */ flex-grow: 1; /* membagi ruang */ flex-shrink: 0; /* tidak mengecil */ flex-basis: 200px; align-self: center; /* override align-items */ order: 2; /* urutan */ }
💡 Tips: Flexbox sangat cocok untuk navigasi, card layout, dan komponen UI yang responsif.
Halaman 19 🎨 CSS — Bab 3

📐 CSS — Grid

Grid adalah layout dua dimensi (baris dan kolom) untuk layout yang lebih kompleks.

Properti Grid Container

.grid { display: grid; grid-template-columns: 1fr 1fr 1fr; /* 3 kolom sama besar */ grid-template-columns: 200px 1fr 2fr; /* 200px | 1 bagian | 2 bagian */ grid-template-rows: auto 200px; gap: 15px; /* jarak antar grid */ justify-items: center; /* horizontal */ align-items: center; /* vertical */ }

Properti Grid Item

.item1 { grid-column: 1 / 3; /* mulai kolom 1 sampai 3 */ grid-row: 1 / 2; } .item2 { grid-column: span 2; /* lebar 2 kolom */ grid-row: span 1; } /* Nama area */ .grid { grid-template-areas: "header header header" "sidebar main main" "footer footer footer"; } .header { grid-area: header; } .sidebar { grid-area: sidebar; } .main { grid-area: main; } .footer { grid-area: footer; }
💡 Tips: Grid lebih powerful untuk layout halaman penuh, sedangkan Flexbox lebih cocok untuk komponen UI.
Halaman 20 🎨 CSS — Bab 3

✨ CSS — Animasi & Transisi

Transisi (Transition)

Transisi memberikan efek halus saat properti berubah.

.button { background: #1a1f3a; transition: all 0.3s ease; /* semua properti, durasi, easing */ transition: background 0.5s, transform 0.2s; } .button:hover { background: #ff6b35; transform: scale(1.05); }

Animasi (Keyframes)

Animasi lebih kompleks dengan @keyframes.

@keyframes slideIn { from { transform: translateX(-100px); opacity: 0; } to { transform: translateX(0); opacity: 1; } } @keyframes pulse { 0% { transform: scale(1); } 50% { transform: scale(1.05); } 100% { transform: scale(1); } } .animate { animation: slideIn 0.8s ease forwards; animation: pulse 2s infinite; animation-delay: 0.5s; animation-duration: 1s; animation-iteration-count: infinite; animation-direction: alternate; }
  • animation-name — nama keyframes.
  • animation-duration — durasi.
  • animation-iteration-count — jumlah pengulangan.
  • animation-direction — arah (normal, reverse, alternate).

⚡ JavaScript — Pengenalan

JavaScript adalah bahasa pemrograman yang membuat website hidup dan interaktif.

Dibuat oleh Brendan Eich pada tahun 1995, sekarang JS adalah bahasa paling populer di dunia.

💡 Tips: Letakkan script di akhir <body> agar tidak menghambat rendering HTML.

Function adalah blok kode yang bisa dipanggil berulang kali.

Halaman 26 ⚡ JavaScript — Bab 2

🖱️ JavaScript — Event

Event adalah aksi yang terjadi di browser (klik, hover, keypress, dll).

Event Listener

// Klik let btn = document.getElementById("myButton"); btn.addEventListener("click", function() { alert("Tombol diklik!"); }); // Dengan arrow function btn.addEventListener("click", () => { console.log("Klik!"); }); // Hapus event btn.removeEventListener("click", handler);

🔗 SQL — JOIN

JOIN digunakan untuk menggabungkan data dari dua atau lebih tabel yang saling berelasi.

INNER JOIN

Data yang cocok di kedua tabel.

SELECT users.name, orders.total, orders.created_at FROM users INNER JOIN orders ON users.id = orders.user_id;

LEFT JOIN

Semua data dari tabel kiri, hanya yang cocok dari kanan.

SELECT users.name, orders.total FROM users LEFT JOIN orders ON users.id = orders.user_id; -- User tanpa order tetap muncul, total = NULL

RIGHT JOIN

Kebalikan dari LEFT JOIN.

SELECT users.name, orders.total FROM users RIGHT JOIN orders ON users.id = orders.user_id;

FULL OUTER JOIN

Semua data dari kedua tabel.

SELECT users.name, orders.total FROM users FULL OUTER JOIN orders ON users.id = orders.user_id;

Self JOIN

Join tabel dengan dirinya sendiri.

SELECT a.name AS employee, b.name AS manager FROM employees a LEFT JOIN employees b ON a.manager_id = b.id;
